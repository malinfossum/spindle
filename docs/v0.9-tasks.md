# Spindle v0.9: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** I can delete the library from Profile or from a "Can't open the library?" panel on the login page, behind one dialog that arms after I type DELETE (SLETT), and nothing of the library is left in the browser afterwards.

**Architecture:** A pure `wipeLibrary(steps)` in `Model/deleteLibrary.js` runs three steps in order and stops at the first failure; `clearLibraryStores()` in `Model/db.js` is its first step. `Controller/Universal/deleteLibrary.js` opens the dialog, runs the wipe with the real steps, and hands over to the existing `logout()`. `openDialog` learns one generic option, `confirmWord`. Other tabs hear the delete through `storageSync.js`.

**Tech Stack:** Vanilla JS modules, Vite 8, Biome, Node `node --test`, the browser pane. No new dependency.

**Spec:** `docs/v0.9-plan.md`. Every task cites the section it implements. Read the spec first; this plan argues from it.

## Global Constraints

- No new dependency, no new host, no change to `public/_headers` or `sw.js`.
- The wipe order is fixed: `clearStores` (one IndexedDB transaction over `covers` and `session`), then `localStorage.removeItem(STORAGE_KEY)`, then `setPref("lookups", "unset")`. A failed first step removes nothing.
- Theme and language are never touched by a delete.
- Every string exists in `Model/i18n/en.js` and `Model/i18n/no.js` with the same key (`test/i18n.test.js` enforces it). No em dashes in new strings.
- User text reaches the DOM through `textContent` or `escapeHtml`, never raw `innerHTML`.
- Controls on one row are 44 px tall and share one bottom edge.
- Commits: plain sentence-case subjects, authored and committed by `Malin Fossum <malinfossum.dev@proton.me>`, no trailers.
- `npm test` and `npm run lint` pass after every task.

## Review Focus

1. **A save in flight when the library is deleted** (this tab or another unlocked one): the library must not come back. Pinned in Task 4 (guard) and the Task 7 pane run.
2. **The word typed in a different case, with spaces, or half typed**: only the shown word arms the button; "delete", " Delete " arm, "DELET" and "DELETED" do not. Pinned in Task 2's Node test.
3. **A damaged stored library**: the login panel shows without the export row, the banner names the panel, and the delete clears it so Create library works. Pinned in Task 7.
4. **IndexedDB refusing the clear**: nothing is removed and the failure notice shows. Pinned in Task 1's Node test (order) and Task 7 (real transaction).
5. **A tab that had gone stale, then deletes and creates a new library**: its saves must work. Pinned in Task 4 (`libraryStale = false`) and Task 7.

```js
// Deleting the library (v0.9). The order is the whole point: the covers and the
// stay-unlocked key go first, in one IndexedDB transaction, and only once that
// has committed does the library itself leave localStorage. A failed first step
// leaves everything exactly as it was. Pure, with the steps passed in, so Node
// can prove the order without a browser.
export async function wipeLibrary({ clearStores, removeLibrary, resetLookups }) {
	try {
		await clearStores();
	} catch (error) {
		return { ok: false, reason: "stores", error };
	}
	removeLibrary();
	resetLookups();
	return { ok: true };
}
```

- [ ] **Step 4: Add `clearLibraryStores` to `Model/db.js`**, after `withStore`:

```js
// v0.9, delete library. Both stores in one transaction, so the covers and the
// stay-unlocked key go together or not at all. withStore() opens one store only.
export async function clearLibraryStores() {
	const db = await openDb();
	const tx = db.transaction([COVERS_STORE, SESSION_STORE], "readwrite");
	tx.objectStore(COVERS_STORE).clear();
	tx.objectStore(SESSION_STORE).clear();
	await new Promise((resolve, reject) => {
		tx.oncomplete = () => resolve();
		tx.onerror = () => reject(tx.error);
		tx.onabort = () => reject(tx.error ?? new Error("IndexedDB transaction aborted"));
	});
}
```

```js
// v0.9. The typed-word check for a destructive confirm. Trimmed and upper-cased,
// then exact: "delete" arms, "DELET" and "DELETED" do not. An empty word never
// matches, so a caller that forgets the word cannot arm the button by default.
export function matchesConfirmWord(typed, word) {
	const want = String(word ?? "").trim().toUpperCase();
	if (!want) return false;
	return String(typed ?? "").trim().toUpperCase() === want;
```

```js
// Delete library (v0.9, docs/v0.9-plan.md). Reached from Profile and from the
// "Can't open the library?" panel on the login page; the same dialog either way.
// No password: the login path cannot ask for one, and anyone holding the device
// can already clear the site's data.

import { clearLibraryStores } from "../../Model/db.js";
import { wipeLibrary } from "../../Model/deleteLibrary.js";
import { t } from "../../Model/i18n/i18n.js";
import { model } from "../../Model/model.js";
import { STORAGE_KEY } from "../../Model/persistence.js";
import { setPref } from "../../Model/prefs.js";
import { setAuthMessage } from "../../Model/viewState.js";
import { openDialog } from "../../View/Universal/dialog.js";
import { updateView } from "../../View/Universal/updateView.js";
import { logout } from "../Login/login.js";

export async function confirmDeleteLibrary() {
	const word = t("delete.word");
	const confirmed = await openDialog({
		title: t("delete.title"),
		body: t("delete.body"),
		confirmText: t("delete.confirm"),
		danger: true,
		confirmWord: word,
		confirmWordLabel: t("delete.wordLabel", { word }),
		confirmWordMismatch: t("delete.wordMismatch", { word }),
	});
	if (!confirmed) return;

	const result = await wipeLibrary({
		clearStores: clearLibraryStores,
		removeLibrary: () => localStorage.removeItem(STORAGE_KEY),
		resetLookups: () => setPref("lookups", "unset"),
	});

	if (!result.ok) {
		console.warn("[delete] the stores would not clear; nothing removed:", result.error);
		setAuthMessage("delete.failed");
		updateView();
		return;
	}

	finishDelete("delete.done");
}

// Shared with storageSync.js: after a delete, here or in another tab. The stale
// flag goes too: the library it was stale against no longer exists, and a new
// library in this tab must be able to save.
export function finishDelete(messageKey) {
	model.app.libraryStale = false;
	model.viewState.loginForgotOpen = false;
	logout();
	// logout() navigates, and navigation clears the notice: set it after.
	setAuthMessage(messageKey, "info");
	updateView();
	document.getElementById("welcome-heading")?.focus();
}
```

If `t()` does not take a params object, read `Model/i18n/i18n.js` and use whatever `profile.title` uses for `{username}`.
